Make a PR description from the current (or given by user in prompt) branch to main. It needs to be simple, short, listing all the changes bunched by groups. Simple to read while describing all the changes made in the branch. Factual (you don't have to guess reason, intention or result, just describe changes).

DO NOT OPEN ANY PR'.

Show the created PRD in a markdown code block so the user can easily copy it.
